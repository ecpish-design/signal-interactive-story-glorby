# GLORB: THE SIGNAL MISSION

GitHub Pages-ready interactive story build.

## Upload
Upload the contents of this folder to the root of a GitHub repository and enable **Settings → Pages → Deploy from branch**.

Required structure:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

No build step or external packages are required.

## Experience design
The story intentionally does **not** quiz students on signal categories during the opening flashback. Early interactions are narrative reconstruction and noticing warnings. The four-category signal system is explicitly taught only after Glorb analyses the crash. The Earth section then transfers that learning from ship/dashboard + Glorb's ears/body to human face/voice/body/movement/space.

## Accessibility
- Keyboard navigation
- Read-aloud via browser Speech Synthesis API
- Transcript modal
- Drag-and-drop signal sorting also has click/tap selection
- Reduced-motion preference respected
- Certificate is print/PDF friendly

## Asset policy in this build
The main story uses the supplied transparent/backgroundless artwork on a white page. Full report-page assets are used only inside optional evidence overlays. The website does not create new illustrated backgrounds.
